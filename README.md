# 8-Bit CPU

A single core, fairly basic 8-bit CPU.

## Instructions

| Instruction   | Opcode |
| :------------ | :----- |
| `ADD`         | `0000` |
| `SUB`         | `0001` |
| `MULT`        | `0100` |
| `DIV`         | `0101` |
| `OUTPUT`      | `0110` |
| `OUTPUT_READ` | `0111` |

## Notes

A lot of this was rewritten from https://github.com/Lemme-lab/Verilog-Simple-CPU/,
but heavily commented, so I can learn Verilog while also building a fairly simple
8-bit CPU.
